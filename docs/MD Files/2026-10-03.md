## 📦 Verified Components
1. **Wearable Firmware (`wearable_withApp/`)**:
   - ESP32-S3 SuperMini BLE GATT server (`0xFFE0 / 0xFFE1`).
   - WS2812B NeoPixel state machine & GPIO0 false-alarm cancel latch.
   - SX1278 433MHz LoRa transmitter.
2. **Receiver Station (`receiver_withDesktop/`)**:
   - Backward-compatible LoRa receiver handling both 101B and 233B packets.
   - USB Serial line emitter at 115200 baud.
   - LAN HTTP upload bridge to port 8888.
3. **Desktop Rescuer (`desktop_app/`)**:
   - Native C# host application with borderless Edge browser launch.
   - Persistent `registrations.json` and `incidents.json`.
   - Leaflet tactical radar map with live telemetry.
4. **Android Companion (`android_app/`)**:
   - 100Hz fused IMU sensor engine with 2.5g crash threshold.
   - MTU-paced BLE chunking (12ms delay).
   - Profile management with Google Drive CDN photo URL formatter.
